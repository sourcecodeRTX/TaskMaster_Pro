<details>
<summary><b>🔒 How Encryption Works</b></summary>

<br>

**Encryption Process:**

1. **Password Entry** → User sets a strong password
2. **Key Derivation** → PBKDF2 generates encryption key (100k iterations)
3. **Data Serialization** → Tasks converted to JSON
4. **Encryption** → AES-256-GCM encrypts the data
5. **URL Generation** → Encrypted data embedded in URL
6. **Sharing** → Send URL + password separately

**Decryption Process:**

1. **URL Detection** → App detects `#share=` parameter
2. **Password Prompt** → User enters password
3. **Key Recreation** → Same PBKDF2 process
4. **Decryption** → AES-256-GCM decrypts data
5. **Import** → Tasks loaded into app

**Security Features:**
- ✅ Zero-knowledge architecture
- ✅ Client-side only (no server)
- ✅ Random salt & IV per encryption
- ✅ Password never stored
- ✅ Data never sent to cloud

</details>

## 🔐 Encryption Deep Dive

### How It Works (Step-by-Step)

<div align="center">

```
User Creates Tasks → Share Button → Enter Password 
     ↓
PBKDF2 Key Derivation (100k iterations)
     ↓
Tasks Serialized to JSON
     ↓
AES-256-GCM Encryption
     ↓
Base64URL Encoding
     ↓
Generate URL with Encrypted Data
     ↓
Share URL + Password (separately)
     ↓
Recipient Opens URL → Enters Password → Decrypt → Import
```

</div>

### Encryption Workflow

<table>
<tr>
<td width="50%">

#### 🔒 **Sharing Tasks (Encryption)**

**Step 1: Prepare**
```javascript
// Collect active tasks
const tasksToShare = tasks.filter(t => !t.completed);

// Serialize to JSON
const dataString = JSON.stringify(tasksToShare);
```

**Step 2: Password Processing**
```javascript
// User enters password
const password = "MyStrongPassword123!";

// Generate random salt (16 bytes)
const salt = crypto.getRandomValues(new Uint8Array(16));

// Derive key using PBKDF2
const key = await crypto.subtle.deriveKey(
  {
    name: "PBKDF2",
    salt: salt,
    iterations: 100000,  // 100k iterations
    hash: "SHA-256"
  },
  passwordKey,
  { name: "AES-GCM", length: 256 },
  false,
  ["encrypt"]
);
```

**Step 3: Encryption**
```javascript
// Generate random IV (12 bytes)
const iv = crypto.getRandomValues(new Uint8Array(12));

// Encrypt data
const encryptedData = await crypto.subtle.encrypt(
  { name: "AES-GCM", iv: iv },
  key,
  encoder.encode(dataString)
);
```

**Step 4: URL Generation**
```javascript
// Combine: salt + iv + encrypted data
const combined = [salt, iv, encryptedData];

// Encode to Base64URL
const encoded = base64URLEncode(combined);

// Create shareable URL
const shareURL = `${window.location.origin}#share=${encoded}`;
```

</td>
<td width="50%">

#### 🔓 **Receiving Tasks (Decryption)**

**Step 1: URL Detection**
```javascript
// Check for share parameter
if (window.location.hash.startsWith('#share=')) {
  const encryptedData = window.location.hash.substr(7);
  showDecryptModal();
}
```

**Step 2: Password Entry**
```javascript
// User enters the same password
const password = promptPassword();

// Decode Base64URL
const combined = base64URLDecode(encryptedData);

// Extract components
const salt = combined.slice(0, 16);
const iv = combined.slice(16, 28);
const ciphertext = combined.slice(28);
```

**Step 3: Key Recreation**
```javascript
// Recreate the same key
const key = await crypto.subtle.deriveKey(
  {
    name: "PBKDF2",
    salt: salt,              // Same salt
    iterations: 100000,      // Same iterations
    hash: "SHA-256"
  },
  passwordKey,
  { name: "AES-GCM", length: 256 },
  false,
  ["decrypt"]
);
```

**Step 4: Decryption & Import**
```javascript
// Decrypt the data
const decryptedData = await crypto.subtle.decrypt(
  { name: "AES-GCM", iv: iv },
  key,
  ciphertext
);

// Parse JSON
const tasks = JSON.parse(decoder.decode(decryptedData));

// Import into app
importTasks(tasks);
```

</td>
</tr>
</table>

### Security Guarantees

<div align="center">

| Feature | Implementation | Benefit |
|---------|---------------|---------|
| **No Server** | 100% client-side | Your data never transmitted |
| **Random Salt** | Crypto.getRandomValues() | Unique key each time |
| **Random IV** | 12-byte nonce | Prevents pattern analysis |
| **PBKDF2** | 100,000 iterations | Slow brute-force attacks |
| **AES-256-GCM** | Authenticated encryption | Tamper detection |
| **Zero-Knowledge** | No password storage | Only you know password |

</div>

  ├─ 🌐 Works offline

  └─ 🔔 Push notifications

### PWA Features

<details>
<summary><b>🌐 Offline Support</b></summary>

<br>

**How It Works:**

```javascript
Service Worker Cache Strategy:
  
  On Install:
    ├─ Cache essential files
    │   ├─ index.html
    │   ├─ style.css
    │   ├─ script.js
    │   └─ manifest.json
    └─ Activate service worker
  
  On Fetch:
    ├─ Check cache first
    ├─ Return cached version
    └─ Fallback to network
  
  Result:
    ✅ Works offline
    ✅ Fast loading
    ✅ No internet needed
```

**What Works Offline:**
- ✅ View all tasks
- ✅ Add new tasks
- ✅ Edit existing tasks
- ✅ Complete/delete tasks
- ✅ Filter and search
- ✅ Full functionality

**What Requires Internet:**
- ⚠️ Initial app load (first time only)
- ⚠️ Encrypted sharing (URL generation)

</details>
